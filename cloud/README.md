# UR3 진단통신 교육 플랫폼

## 1. 목적

Universal Robots **UR3 (CB3)** 협동로봇을 이용해, 입문자가 **진단통신**의 핵심 개념
— 신호 요청/응답, 명령 송신 — 을 직관적으로 이해하도록 돕는 **교육용 플랫폼**임.

사용자는 PC/태블릿 웹 UI에서 인터넷을 통해 **로봇 실시간 데이터를 요청**(예: 관절 각도)하고,
**속도 제한이 걸린 단순 모션 명령을 송신**함. 라즈베리 파이가 클라우드 메시징 계층(MQTT)과
로봇 고유 실시간 프로토콜(RTDE) 사이를 변환하는 엣지 게이트웨이 역할을 함. 산업용 도구 수준이
아니라 **요청/응답 흐름의 명확한 시각화**에 초점을 둠.

> 범위 주의: 교육용 데모임. 실시간 제어 루프는 라즈베리 파이 ↔ 컨트롤 박스 사이 **로컬**에
> 유지하고, 클라우드로는 **이산적·고수준 명령과 텔레메트리만** 오감.

---

## 2. 전체 구조

서로 다른 3개 프로토콜이 연결되며, 구간마다 "언어(프로토콜)"가 달라 중간의 라즈베리 파이가
변환을 수행함.

```
                         (인터넷 / Wi-Fi)                (인터넷 / Wi-Fi)
 [ PC / 태블릿 ]  <--- MQTT over WebSocket --->  [ 클라우드 MQTT 브로커 ]  <--- MQTT --->  ...
   웹 UI 전용                                      (HiveMQ / EMQX, 무료)
   (ROS·ur_rtde 없음)
                                                                                          |
                                                                                          v
 ┌──────────────────────────────────────────────────────────────────────────────────────────┐
 │ [ 라즈베리 파이 4 ]   (Ubuntu, 엣지 게이트웨이)                                              │
 │    - MQTT 클라이언트  (paho-mqtt)                                                          │
 │    - RTDE 클라이언트  (ur_rtde:  RTDEReceiveInterface / RTDEControlInterface)              │
 │    변환  MQTT  <-->  RTDE / URScript                                                       │
 └──────────────────────────────────────────────────────────────────────────────────────────┘
                                  |
                                  |  RTDE (TCP 30004, 읽기 @125 Hz)  +  URScript (TCP 30002, 제어)
                                  v
                       [ UR 컨트롤 박스 (CB3) ]
                          PolyScope / URControl  (실시간 제어기, 안전)
                                  |
                                  |  내부 실시간 필드버스 (UR 독자)
                                  v
                       [ UR3 로봇 암 ]  (6관절: 모터 + 엔코더, OS 없음)
```

**연결 및 전원**

| 구간 | 매체 | 비고 |
|------|------|------|
| UR3 암 ↔ 컨트롤 박스 | 전용 로봇 케이블 | 암에는 OS 없음, 컨트롤 박스가 두뇌 |
| 컨트롤 박스 ↔ 라즈베리 파이 | LAN (이더넷) | RTDE + URScript over TCP/IP, 동일 서브넷 |
| 라즈베리 파이 ↔ 클라우드 브로커 | Wi-Fi / LTE (인터넷) | MQTT |
| 클라우드 브로커 ↔ PC/태블릿 | 인터넷 / Wi-Fi | MQTT over WebSocket |
| 컨트롤 박스 전원 | 100–240 VAC, 50–60 Hz (220 V) | 주전원, IEC C20 인렛 |
| 라즈베리 파이 전원 | 5 V DC USB-C (5.1 V / 3 A 어댑터) | 어댑터를 220 V 콘센트에 연결 |

## 3. 구성 요소 (필요 하드웨어 / 서비스)

| # | 구성 요소 | 사양 / 비고 |
|---|-----------|-------------|
| 1 | 로봇 암 | Universal Robots **UR3** (CB3 시리즈, 6축, 페이로드 3 kg, 도달거리 500 mm) |
| 2 | 컨트롤 박스 | UR CB3 컨트롤 박스 (이더넷 내장, 주전원 100–240 VAC) |
| 3 | 티치 펜던트 | PolyScope **3.x** 터치스크린 펜던트 (컨트롤 박스에 연결) |
| 4 | 엣지 보드 | **라즈베리 파이 4** (4 GB 이상 권장), Ubuntu, 5 V/3 A USB-C 전원 |
| 5 | LAN 케이블 | 컨트롤 박스 ↔ 라즈베리 파이 (이더넷) |
| 6 | 인터넷 회선 | Wi-Fi (Pi 4 온보드) 또는 LTE 모뎀 |
| 7 | 클라우드 MQTT 브로커 | **HiveMQ Cloud** 또는 **EMQX Cloud** (무료 티어) |
| 8 | 클라이언트 단말 | 최신 웹 브라우저 탑재 PC 또는 태블릿 (MQTT over WebSocket) |

## 소프트웨어 스택 (요약)

| 계층 | 선택 |
|------|------|
| Pi OS | Ubuntu (Server/Desktop) |
| Pi ↔ 컨트롤 박스 | `ur_rtde` (Python/C++ RTDE 클라이언트) — **ROS2·`ur_robot_driver` 미사용** |
| Pi ↔ 클라우드 | `paho-mqtt` |
| 클라이언트 UI | HTML/JS 웹앱 (MQTT over WebSocket) |

상세 역할·읽을 수 있는 값·프로토콜 매트릭스는 `Requirements_Definition.md` 참조.
